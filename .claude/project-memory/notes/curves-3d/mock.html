Curves in 3D space, with handles to edit

What curves do today

Curve objects already exist (the Bézier series, #453 to #474): each is an object in the Scene card with its own transform, saved in the scene file, and makes a Line, Tube, Lathe, Along, Brush path or Guide live until Bake. What is missing is everything that lets one live away from a model.

Drawing needs a modelA drag only collects points where the pen is over a surface, and the first tapped point must land on one. Only later taps can fall off the model, onto the plane facing the view through the last point.
No way to add oneNothing in the Add menu makes a curve. The only start is drawing on a model, so an empty scene cannot get a curve at all.
Points follow the surfaceA dragged point snaps onto any surface under the pen, else the view plane. There is no moving along an axis, no gizmo, and one point at a time.
Two handle kinds, one at a timeA point is smooth or a corner, toggled by a tap. Handles show on every point, and there is no selection of several points.
Grows only by insertingA tap on the line inserts a point, but nothing extends a curve past its ends, joins two curves or reverses one.
No numbersA point's position, radius and twist (the twist is stored) cannot be typed or seen.

The build, in 9 PRs

Each PR merges on its own into odin-sculpt and leaves the app working. None touches the brush, stroke or culling paths, so sculpting speed cannot change; curves are tens of points, and an edit costs well under 0.1 ms plus the live tube's rebuild, which exists today.

1 · Draw anywhere new

The drawing plane (Surface, View, Floor, Front, Side) for drags and taps, drawn as a grid while drawing; View goes through the view's centre for the first point and through the last point after. A dragged point keeps to its plane unless Surface is chosen. Setting saved; script set curve_plane view.

2 · Add › Curve new

Line, Bézier, Circle, Spiral and Helix in the Add menu, at the add point, facing the view, sized to the view; one undo step; selected with the Curve tool in Edit. Script add_curve circle.

3 · Edit tab and point selection new

Draw and Edit tabs (Tab), a selection of points (tap, Shift, box, A, Escape), handles of the selected points shown, double-tap for corner, Delete deletes the selection. The selection is not saved in the file.

4 · Gizmo on points new

The move gizmo on the selection: arrows, centre, turn ring and size knob, with the gizmo's orientations; G, R, S with X, Y, Z; Snap's grid steps. A gizmo drag is one undo step.

5 · Handle types new

geom.Bezier_Point.corner becomes a Handle_Type (Auto, Aligned, Free, Vector) with bezier_auto_handles; the CURV chunk and the scene version change together, old files refused as the rules say.

6 · Grow, join, split, reverse new

＋ nubs at the ends, taps in Draw that continue from a picked end, Join (two ends of two curves into one curve, or the two ends of one into a loop), Split at a point, Reverse.

7 · Profile pad new

The tube's profile becomes a closed 2D Bézier stored with the curve (in place of the Tube_Profile enum); the presets fill it. The card's pad edits it with points, handles, the four types and Mirror. geom.bezier_tube sweeps the sampled outline; the CURV chunk carries it. Bake keeps the shape.

8 · Width along new

An open 2D curve from start to end, multiplying the radius along the length, with its pad and four presets; the tube reads it, and Along's copies grow and shrink with it. Sharp profile corners keep hard edges on the swept mesh.

9 · Point numbers, help and checks

The Point section (X, Y, Z, radius, tilt), README and the Help glossary, touch scenarios for each gesture, screenshots described.

Choices, with what I will do unless you say otherwise

  1. Where you edit points. In the Curve tool's Edit tab (Tab switches, and Tab with a curve selected in any tool goes there). The other way is Blender's: points editable from any tool whenever a curve is selected, which clashes with brush strokes.
  2. The plane off the model. View, through the view's centre and then the last point, as today's taps already do. Floor is the other good default if you mostly build from the ground up.
  3. A tap on a point. Selects it, and a double-tap switches smooth and corner. Today a single tap switches corner, which a selection cannot share.
