Materials · A · Shelf

A · Shelf. Substance's shelf in one card: the selected object's material as a big live ball on top, category chips, a 4-across grid of balls, and Edit swapping the grid for the layer folds. Imports are the first chip, grouped per object.

The balls here are CSS stand-ins. In the app each one is drawn by our own renderer (the viewport's PBR path under the scene's environment) into a ball atlas. Lens theme tokens; card 312 pt. All directions · design note: design.md

Why A (recommended)

  • Same 312 pt card as every other card: fits the 1180 × 820 tablet beside the model.
  • Browsing first, as in Substance's shelf; the existing try-on scrub works straight on the grid.
  • The import is the first chip and groups per object, which answers "I can't see my Blender materials".
  • Cost: browsing and editing are not visible together; Edit is one tap, and ‹ Shelf goes back.

States

  • Finger: tap applies, a slide scrubs (tentative vertically, so the card still scrolls), a hold opens Favourite / Select objects using it / Copy values.
  • Chips scroll sideways; the chosen chip is remembered. With polygroups the preview says "group 3" and Apply to gets Group.
  • No selection: the big ball is the one new objects take.
