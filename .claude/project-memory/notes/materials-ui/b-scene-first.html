Materials · B · Scene first

B · Scene first. Marmoset and Blender's way: the card lists the selected object's own materials (one per group, as the file brought them) with their values, and the editor sits under them. Browsing is the Library sheet, opened by Replace… or Library, where sliding tries balls on the chosen material.

The balls here are CSS stand-ins. In the app each one is drawn by our own renderer (the viewport's PBR path under the scene's environment) into a ball atlas. Lens theme tokens; card 312 pt. All directions · design note: design.md
