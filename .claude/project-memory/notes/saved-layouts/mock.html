Your own layouts

Each space still keeps one live layout that saves itself. On top of that you can save a layout under a name and later stamp it onto any space from the tab's menu. A saved layout is a stamp: loading it copies it into the space you're in, and from then on that space just keeps changing as usual. Nothing tracks which layout is "active".

Try this

  1. Drag the dock's faint grip to another edge and pin a card.
  2. Open the chevron ▾ beside the tabs, then tap Save layout as…, name it and save.
  3. Switch to Render, open the menu and tap your layout. Render now looks like it.
  4. Try ⋯ on a row: Update to now, Rename, Delete (with Undo).
  5. Save again under a name that exists. It asks before replacing.

Rules

  • A saved layout holds what a space's layout holds: docks and their buttons, bars shown or hidden, pinned and floating cards, the view grid and the pass.
  • It loads into any space. Your brushes and shelf pages are never part of it, so loading one never touches them.
  • A tick marks a saved layout that matches the space exactly right now. Change anything and the tick goes. There's no second dot or "modified" state.
  • Reset layout still means "as the app ships". Your saved layouts are untouched by it.
  • Also in Search and the command palette: Save layout as, and Load layout: name for each one, so a key or a pie slot can load one.
  • Kept in the settings file, so they survive restarts. No limit beyond common sense (the list scrolls past 8).
