Phase 3c: what the next PR changes

The page draws the changes on top of today's screenshots, so they line up with what you see in the app.

Readout, view gizmo and Tool card Next PR

  1. 1The readout keeps the vertex count only. Memory and GPU time move behind a Show performance switch in Settings, off by default (ZBrush and Nomad keep timings out of the view).
  2. 2An open card no longer covers the view gizmo: the gizmo steps left of the card, as Nomad's does beside its panels.
  3. 3The Tool card stops repeating Size and Strength. The brush bar already shows both, and the card's header still says "Draw · 60 px".
  4. 4Colour's folded summary is a swatch instead of a hex code.

Library Built, in the next PR

  1. 1The field said "Search 706" while All said 45, because it searches brushes, alphas and buttons together. It now says Search brushes and tools.

Phase 4: touch density

Today iPad and desktop share one density. Phase 4 gives touch its own names and target sizes and leaves the mouse layout as it is.

Touch: names where a finger needs them Phase 4

  1. 1On a touch screen the rail names its buttons, as ZBrush for iPad does. A mouse keeps the bare icons and their tooltips.
  2. 2The dial's four sectors carry small names under their icons.
  3. 3The page names under the shelf keep their look, but each gets a 44 pt touch target (dashed). Today they are 24 pt.

Touch: no keyboard hints without a keyboard Phase 4

  1. 1On an iPad with no keyboard attached, the key hints go ("Enter run · Tab show where it lives", "D and Shift+D go up and down"). They come back when a keyboard is attached.

Today the Mesh card is one list of nine sections. Grouping it by what you're trying to do makes it quicker to scan (ZBrush's Geometry palette and Blender's Remesh panel both split this way). Nothing moves to another card.

This is one of the phase 5 merges in the report. Those change where things live, so they wait for you. The others:

  • A Common block at the top of the Tool card: the four controls a brush is changed by most, with the rest folded below.
  • Fewer names for surface concepts (there are 17 today: Shading, Pass, Look, Material Preview…). This needs its own short proposal before any code.

Phase 6: polish and the last council round

  • Spacing literals go to tokens (the audit counts 170 left) and the 10 hand-scaled type sizes go to ramp steps.
  • Each card's header and section rhythm gets checked against the 8 pt grid.
  • A final council: three critics score all 14 screens on desktop and iPad against ZBrush, Nomad and Uniform. The round 0 mean was 6.3 and it is now 6.8. The target is 8 or more on every screen, otherwise the lowest categories go round again.
