Live stack: Mirror, Array and the other modifiers

Plan and mock, 5 November 2026. Nothing is built yet; four picks for Bolt are at the end.

What we build. One card, the Live stack, on every object. It holds rows that change how the object is shown without changing what it stores, so you can switch them off, tune them and take them away at any time. Each row has an Apply that bakes it, as one undo step.

The rule that makes it fast. On a sculpt, the stack only makes copies: Mirror, Array, Radial and Along a curve. Every copy is the same GPU mesh drawn again under another placing, so a stroke costs exactly what it costs today however many copies there are, and you can sculpt on any copy. Rows that change the polygons (Thickness, Bevel, Smooth) stay on cages, where Model mode already rebuilds them live because cages are small. A sculpt meets those needs with things we already have (levels, layers, the skin, Live boolean).

Pushback. Blender's free stack, where any modifier goes on any mesh in any order, is the part we should not copy. Its CPU re-evaluates the mesh after every change, which is why sculpting with modifiers on is slow in Blender, and it would break the "no hitch on a stroke" rule at 5M and up. We keep the idea (non-destructive, switch off, apply later) and drop that engine.

The order is fixed: Mirror, then the copies rows, then Thickness, Bevel, Smooth. Each kind appears once. A fixed order means every combination gives the result you expect, and there is nothing to drag about (pick 2).

Sculpting on copies

  • A press on any copy picks the object and the stroke goes into the source through that copy's inverse placing. This is the same path brush symmetry already uses for its images, made general: symmetry's images become a list of placings (mirror, radial, array, curve), and each dab is put into the source by its copy's inverse. The source then shows everywhere, as in Nomad.
  • The brush ring draws on every copy, as the mirrored rings do now.
  • Copies are similarities (turn, move, even size, plus the mirror's reflection), so a dab's radius scales by the copy's size and nothing bends.
  • Mirror on a sculpt does not cut the mesh, so levels, the mask, layers and HD are all kept. The − half is still stored and is edited by the locked symmetry, but it is not drawn; the image of the + half is drawn in its place, clipped exactly at the plane. Apply runs Mirror and weld.

What changes underneath

  • Render and GPU (needs a design note first, by AGENTS.md's rule): a Draw_Item gets a list of placings drawn as instances of one mesh, a "mirrored" flag that flips the front face, and a clip plane (Vulkan's clip distance is already turned on in vk_device.odin; Metal has clip_distance; on WebGPU it is the optional clip-distances feature, otherwise a discard). GPU culling and the idle cache work per placing.
  • Object: a Stack value per object (plain settings, no meshes). poly.Live becomes the cage half of it.
  • Undo: a new History entry, "Stack", holding the row before and after. It is small, with no mesh. Apply is a swap entry, following object_remesh.
  • Files: a STAK chunk per object, with the cage's live fields moved into it. There are no old readers (pre-release rule).
  • Export, the Blender link and Send: Export bakes the stack by default (option "Bake the live stack", on); the Blender link sends it baked; Send carries the stack as it is, since both ends are this app.
  • Rebuilds: Remesh, Decimate, Quad Remesh and booleans keep the stack, because sculpt rows are only placings.

Not in the stack, and why

  • Live deformers on sculpts (Bend, Twist, Taper, Lattice, Curve). A brush would have to work in the bent space, which needs the inverse of a bend for every dab. Blender's approximate form of this is slow and imprecise. The Deformers card with Adjust last, plus sculpt layers, already meets the need.
  • Remesh, Decimate and Displace as modifiers: Rebuild, the simplified copies and sculpt layers meet these needs, and doing them live would hitch strokes.
  • Scatter on the surface (NanoMesh, Geometry Nodes): a later plan, once copies exist. It would reuse the same placings.

Picks for Bolt

1. Mirror and weld. Recommended: it becomes the Mirror row's Apply, and the Modify topology button goes (one UI per thing). Other choice: keep both.
2. Row order. Recommended: fixed order, one of each kind. Other choice: drag to reorder and allow repeats, as Blender does, which adds order mistakes and a harder card on touch.
3. Live deformers on cages (M7). Recommended: later, once M1 to M6 are tried. Other choice: build it now.
4. Where the card lives. Recommended: the Object page, with a rail button that opens the same card. Other choice: inside the Scene card as a section per object.
