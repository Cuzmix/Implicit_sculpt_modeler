One layout per space

Each space remembers its own layout. Shape Sculpt one way and Render another, then switch tabs and each comes back as you left it. There are no named workspaces to save, pick or rename. The tab's chevron has Reset layout, and an amber dot shows a space that differs from how it ships.

Try this

  1. In Sculpt, drag the dock's faint grip to the left or top edge.
  2. Tap a dock button to open a card, then pin it with the square.
  3. Switch to Render and change something there too.
  4. Switch back. Each space kept its own layout, and the changed ones carry the amber dot.
  5. Open the chevron beside the tabs and pick Reset layout.

What goes

  • Named workspaces ("My sculpt 2", "Paint setup") and the Workspaces menu.
  • Save as, Rename, Revert, Delete, Export and Import workspace.
  • A layout is kept as you shape it, with no Save step. It lives in the settings, so it survives a restart and an update.
