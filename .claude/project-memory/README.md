# Project memory (a snapshot)

What the cloud project "Optimized Sculpting" knew on 2026-11-05, copied here so a Claude Code
session on any machine can read it. It is a snapshot: nothing keeps it in step with the cloud
project's memory, and it is not edited by the cloud threads. Copy it again to refresh it.

- `memory/MEMORY.md` is the index: Bolt's standing rules first (working mode, devices, what is
  vetoed), then every plan with its PR numbers and the memory file that holds its detail.
- `memory/*.md` are those files, one subject each, with links between them as `[[name]]`.
- `threads.md` lists the project's threads and which are still open or waiting on Bolt.
- `notes/` holds the designs, mocks (HTML under 200 KB) and patches from the project's shared
  folder. Images, zips and the large HTML sheets were left out; links to claude.ai artifacts in
  the memory files open in a browser signed in as Bolt.

Where a memory file and the code disagree, the code wins: memory says what was true when written.
The rules in AGENTS.md are the repository's; the working-mode rules in MEMORY.md are Bolt's
preferences for how agents work with him (merging, testing, GitHub Actions, gate runs).
