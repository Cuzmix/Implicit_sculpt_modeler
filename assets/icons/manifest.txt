# The interface's icons: one line per meaning, `NAME group source`, where source is
# pack:name. The packs are Phosphor (ph, MIT: a regular, a bold and a duotone drawing of each),
# Tabler (tb, MIT) and Lucide (lu, ISC), the best drawing of each meaning wherever it is,
# and our own (own, assets/icons/svg/own) for sculpting meanings no pack draws well;
# a stroked drawing is outlined at Phosphor's stroke width so the set reads as one.
# Each name stands for one meaning and no two names share a drawing (icons_build.py refuses
# it): a second thing that looks the same is a second meaning wanting its own picture.
# Groups colour the icon in the Colour icon style: app, sculpt, mask, paint, model, view,
# render, file. Run `python scripts/icons_build.py` after editing; `check` runs --check.
